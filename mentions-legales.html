Mentions Légales

1. Présentation du projet

TaskMaster est une application web de démonstration réalisée dans le cadre d'un portfolio de développeur. Ce projet a pour but de présenter des compétences techniques en développement JavaScript Vanilla et en intégration CSS moderne.

4. Protection des données

TaskMaster est une application respectueuse de votre vie privée :

  • Aucune donnée personnelle n'est collectée ou transmise à des serveurs tiers.
  • L'ensemble de vos tâches et préférences est stocké exclusivement en local sur votre appareil via l'API localStorage de votre navigateur.
  • Vous pouvez supprimer l'intégralité de vos données à tout moment en vidant le cache de votre navigateur.
